# Privacy Policy Draft

Dalhousie Companion collects and processes user data only to provide the app's core functionality.

## Data handled

- Account information used for sign in
- Profile details stored in Firebase
- Shared content such as meetings, resources, and notifications
- File uploads selected by authorized users

## Data storage

The app uses Firebase Authentication, Firestore, and Firebase Storage.

## Sharing

The app does not sell personal data.
Data is shared only with the services required to operate the app and only within the rules of the configured Firebase project.

## Access

Only authorized users can access role-restricted data.
Administrators may manage records according to the app's permissions model.
